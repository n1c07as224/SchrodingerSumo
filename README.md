# SchrodingerSumo

Codigo para controlar el robot sumo autonomo **"Schrodinger Sumo"** mediante logica de estados.

**Integrantes:**
- Nicolas Arredondo Jaime
- Christopher Guijosa Vaca
- Leonardo Zavala Angeles



## Estructura del repositorio
- **main:** Contiene la versión estable y final del código del robot sumo. Esta rama solo incluye modificaciones que fueron aprobadas por los tres integrantes del equipo de programación.


- **ramas individuales:** Cada integrante cuenta con una rama propia sin restricciones para experimentar y desarrollar el código de forma independiente antes de integrarlo a la rama main.
